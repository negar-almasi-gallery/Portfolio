# راهنمای مدیریت گالری نگار الماسی

**آدرس سایت:** https://negar-almasi-gallery.github.io/Portfolio/

**مخزن مدیریت:** https://github.com/negar-almasi-gallery/Portfolio

این سایت به‌طور خودکار از فایل‌های MP4 پوشه `videos` گالری می‌سازد. برای افزودن اثر جدید نیازی به ویرایش `index.html`، کدنویسی یا نصب برنامه نیست.

## ۱) اضافه‌کردن ویدیو، قدم‌به‌قدم (از موبایل یا رایانه)

1. با حساب **negar-almasi-gallery** وارد GitHub شو.
2. این پوشه را باز کن: https://github.com/negar-almasi-gallery/Portfolio/tree/main/videos
3. بالای فهرست فایل‌ها **Add file → Upload files** را بزن؛ در موبایل ممکن است گزینه زیر منوی `…` باشد و فعال‌کردن **Desktop site** کمک کند.
4. یک فایل ویدیویی MP4 با نام انگلیسی کوتاه و یکتا انتخاب کن؛ مثل `02-vase.mp4` یا `03-relief.mp4`. فقط از حروف لاتین، عدد و خط تیره استفاده کن. فایل جدید نباید نام ویدیوهای قبلی را داشته باشد.
5. پایین صفحه **Commit changes** و سپس **Commit directly to the main branch** را تأیید کن.
6. سایت بعد از اجرای موفق **pages build and deployment**، ویدیوی جدید را به گالری اضافه می‌کند. آدرس سایت همان است و QR قبلی تغییر نمی‌کند.

**فقط همین شش قدم برای نمایش یک ویدیو کافی است.** اگر عنوان یا عکس جلد جداگانه ندهی، ویدیو باز هم قابل‌نمایش است؛ فقط یک عنوان پیش‌فرض برگرفته از نام فایل و پس‌زمینه گرافیکی زرد خواهد داشت.

**حجم:** در آپلود از مرورگر GitHub، هر فایل باید حداکثر **۲۵ MiB** باشد. ویدیوها را در صورت نیاز با خروجی MP4/H.264 فشرده کن. انتشار ویدیوهای عمومی یعنی هر شخصی می‌تواند آن‌ها را ببیند و دریافت کند.

## ۲) نوشتن عنوان و توضیح زیبا برای یک ویدیو (اختیاری اما پیشنهادی)

1. این فایل را باز کن: https://github.com/negar-almasi-gallery/Portfolio/blob/main/_data/artworks.yml
2. گزینه **Edit this file** (مداد) را بزن.
3. زیر اثرهای موجود، با دقت این نمونه را اضافه کن؛ نام داخل گیومه باید *دقیقاً* نام ویدیو بدون `.mp4` باشد:

```yaml
"02-vase":
  title: "گلدان سفالی دست‌ساز"
  category: "ظروف سفالی"
  technique: "فرم‌دهی با دست"
  description: "گلدان دست‌ساز با نقوش تزئینی؛ طراحی و اجرای اثر توسط نگار الماسی."
  featured: false
```

4. روی **Commit changes** بزن. متن پس از انتشار جدید سایت به‌روز می‌شود.

**نکات مهم:** برای هر مقدار متنی، گیومه‌های دوبل را حفظ کن. فاصله تورفتگی قبل از `title` و سطرهای بعدی دقیقاً **دو فاصله** است؛ از Tab استفاده نکن. اگر مطمئن نیستی، به‌جای ویرایش فایل، فقط ویدیو را آپلود کن تا ساختار سایت آسیب نبیند.

## ۳) انتخاب عکس جلد واقعی (اختیاری)

1. یک تصویر JPG از همان اثر آماده کن (می‌توانی از ویدیو یک فریم واضح استخراج کنی).
2. نام فایل عکس باید با ویدیو یکسان باشد، مثل `02-vase.jpg`.
3. وارد https://github.com/negar-almasi-gallery/Portfolio/tree/main/posters شو و عکس را با **Add file → Upload files** قرار بده؛ سپس Commit کن.
4. با این کار کارت اثر عکس واقعی خواهد داشت. بدون عکس نیز کارت زرد ساده به‌درستی کار می‌کند.

## ۴) حذف اثر

1. وارد `videos` شو، ویدیوی موردنظر را انتخاب کن و از منوی سه‌نقطه **Delete file** را بزن، سپس Commit کن.
2. گالری بعد از انتشار جدید آن اثر را دیگر نشان نمی‌دهد.
3. برای مرتب ماندن مخزن، عکس هم‌نام را از پوشه `posters` و مشخصات مربوط به آن را از `_data/artworks.yml` نیز می‌توانی حذف کنی (اختیاری).

## ۵) تغییر ویدیو یا اطلاعات اثری که قبلاً ثبت شده

- **فقط تغییر عنوان/توضیح:** فایل `_data/artworks.yml` را ویرایش و Commit کن؛ ویدیو عوض نمی‌شود.
- **جایگزینی ویدیو:** در `videos` فایل قدیمی را حذف کن و فایل جدید را با **همان نام** بارگذاری کن. بهتر است این دو کار در دو Commit جداگانه انجام شوند.
- **جایگزینی جلد:** در `posters` تصویر قبلی را حذف و JPG جدیدی با همان نام آپلود کن.
- **تغییر ترتیب نمایش:** اثری که در `_data/artworks.yml` دارای `featured: true` باشد ابتدا نمایش داده می‌شود. نام‌های `01-...`، `02-...` و ... ترتیب بقیه را مشخص می‌کنند.

## ۶) اگر ویدیوی جدید ظاهر نشد

1. بررسی کن ویدیو واقعاً داخل `videos` و در شاخه `main` باشد، نه پوشه دیگری.
2. نام فایل حتماً با `.mp4` باشد و ویدیو در مرورگر قابل پخش باشد.
3. بخش https://github.com/negar-almasi-gallery/Portfolio/actions را باز کن و اجرای **pages build and deployment** را بررسی کن؛ نتیجه سبز یعنی انتشار انجام شده است.
4. صفحه سایت را یک بار تازه‌سازی کن. اگر تغییر مشخصات در YAML باعث خطای انتشار شد، تغییر اخیر را برگردان یا از کسی کمک بگیر.

## یادآوری امنیتی

مخزن سایت **Public** است و تمام ویدیوها، تصاویر و توضیحات آن برای عموم قابل‌مشاهده‌اند. اطلاعات خصوصی، رمز، شماره‌حساب و فایل غیرقابل‌انتشار داخل مخزن قرار نده. QR فقط به آدرس اصلی سایت وصل است و با تغییر آثار ثابت می‌ماند.
