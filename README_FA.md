# راهنمای نگار برای مدیریت گالری 🌼

این سایت برای حساب GitHub به نام `negar-almasi-gallery` و مخزن `Portfolio` آماده شده است.

## ۱. اضافه‌کردن یک ویدیوی جدید (بدون برنامه‌نویسی)

1. در GitHub وارد حساب خودت شو و به مخزن `Portfolio` برو.
2. پوشه `videos` را باز کن.
3. گزینه **Add file → Upload files** را انتخاب کن.
4. ویدیوی MP4 جدید را انتخاب کن. بهتر است نام فایل کوتاه و یکتا باشد، مثلاً `02-vase.mp4`.
5. پایین صفحه **Commit changes** را بزن.
6. صفحه سایت پس از انتشار مجدد، خودش ویدیو را نشان می‌دهد. نیازی نیست `index.html` را تغییر بدهی.

**محدودیت:** آپلود از مرورگر GitHub برای هر فایل حداکثر **۲۵ مگابایت** است. ویدیوهای بلند را ابتدا فشرده کن.

## ۲. انتخاب عنوان، توضیح و دسته‌بندی اثر (اختیاری)

1. وارد `_data/artworks.yml` شو.
2. روی آیکن مداد (Edit this file) بزن.
3. مثل نمونه زیر، سطرهای اثر جدید را اضافه کن (نام کلید دقیقاً نام فایل بدون پسوند mp4 است):

```yaml
"02-vase":
  title: "گلدان سفالی دست‌ساز"
  category: "ظروف سفالی"
  technique: "فرم‌دهی با دست"
  description: "گلدان سفالی با نقوش ساده و اجرای دستی."
```

4. **Commit changes** را بزن. عنوان و توضیح در گالری عوض می‌شود.

> اگر این مرحله را انجام ندهی، ویدیو باز هم نمایش داده می‌شود؛ فقط عنوان پیش‌فرض از نام فایل گرفته می‌شود.

## ۳. عکس جلد برای ویدیو (اختیاری)

اگر می‌خواهی عکس زیبایی از محصول روی کارت دیده شود، عکس JPG را با **همان نام** ویدیو در پوشه `posters` بگذار. مثلاً برای `02-vase.mp4`، فایل `posters/02-vase.jpg` را اضافه کن. اگر عکس نباشد یک زمینه زرد جای آن نمایش داده می‌شود. ویدیو در هر دو حالت پخش می‌شود.

## ۴. حذف ویدیو

1. وارد پوشه `videos` شو و روی فایل ویدیو بزن.
2. از منوی سه‌نقطه بالای فایل **Delete file** را انتخاب کن.
3. حذف را با **Commit changes** تأیید کن.
4. بعد از انتشار، اثر به صورت خودکار از سایت حذف می‌شود. در صورت تمایل عکس جلد مرتبط را از `posters` هم حذف کن.

## ۵. تعویض ویدیوی قدیمی

ویدیوی قبلی را حذف کن و فایل MP4 جدید را با **همان نام قبلی** آپلود کن. اگر نام را تغییر دهی، کلید مربوط به آن در `_data/artworks.yml` را هم عوض کن.

## ۶. انتشار اولیه سایت

1. یک مخزن **Public** به نام `Portfolio` بساز و همه فایل‌های این بسته را با حفظ پوشه‌ها در آن قرار بده.
2. در **Settings → Pages**، بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
3. شاخه **main** و پوشه **/(root)** را انتخاب کن و **Save** بزن.
4. آدرس سایت: https://negar-almasi-gallery.github.io/Portfolio/

## ۷. نکات مهم

- مخزن Public است؛ ویدیوها و فایل‌ها برای همه قابل مشاهده و دانلود هستند.
- برای کارهای هنریِ متعلق به شخص دیگر هیچ فایلی را بدون اجازه منتشر نکن.
- رمز GitHub، رمز جیمیل یا کد ورود را به کسی نده.
- فقط یک QR ثابت برای آدرس صفحه اصلی بساز؛ با اضافه یا حذف آثار، QR عوض نمی‌شود.
- برای تغییر مشخصات هنرمند یا سبک ظاهری، از توسعه‌دهنده کمک بگیر؛ برای ویدیوها نیازی به کدنویسی نیست.
