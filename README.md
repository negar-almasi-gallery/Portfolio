# Negar Almasi — Ceramic Art Portfolio

A Persian RTL, yellow-themed Jekyll gallery published via GitHub Pages.

- Add an MP4 to `videos/` to list it automatically at build time.
- Optional artwork metadata: `_data/artworks.yml` (keyed by MP4 basename).
- Optional real thumbnail: `posters/<video-basename>.jpg`.
- Videos open in an accessible dialog with a shareable link to each artwork.
- A single static QR code links to the gallery's homepage.

See [راهنمای فارسی مدیریت آثار](README_FA.md) for step-by-step instructions for the artist.
